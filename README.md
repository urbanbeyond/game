# BRICKLAND · 브릭랜드

브라우저에서 즐기는 작은 3D 블록 샌드박스입니다. 절차적으로 생성되는 초원과 강, 나무, 다리와 유적을 탐험하고 블록을 부수거나 자유롭게 쌓을 수 있습니다. 마인크래프트에서 영감을 받은 독립적인 프로토타입이며, 해당 게임의 코드나 에셋을 사용하지 않습니다.

주황색 픽셀 캐릭터 **히나냥**을 조작하는 3인칭 숲속 탐험으로 업그레이드했습니다. 사용자 제공 스티커의 주황색·검은 테두리·흰 무늬를 11×6 픽셀 입체 모델로 옮겼으며, 걸음·달리기·점프와 꼬리 애니메이션이 적용됩니다. 풀꽃과 버섯이 있는 기존 숲을 탐험할 수 있습니다. 원본 이미지의 Windows 파일 경로에 의존하지 않습니다.

## 시작하기

Node.js 24 LTS와 npm을 사용합니다. 서버나 API 키, 데이터베이스가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

Vite가 출력하는 개발 서버 주소를 데스크톱 브라우저로 엽니다. WebGL과 키보드·마우스가 필요합니다. 화면의 **숲으로 출발하기** 버튼을 누르면 마우스가 게임에 고정됩니다. `Esc`로 해제합니다. 모바일 화면 배치는 지원하지만 터치 게임 조작은 아직 제공하지 않습니다.

## 조작

| 입력          | 동작                                |
| ------------- | ----------------------------------- |
| WASD / 방향키 | 이동                                |
| 마우스        | 시선 이동                           |
| Space         | 점프                                |
| Shift         | 달리기                              |
| 왼쪽 클릭     | 블록 부수기                         |
| 오른쪽 클릭   | 블록 쌓기                           |
| 숫자 1–7 / 휠 | 잔디·흙·돌·나무·잎·모래·벽돌 선택   |
| H             | 조작 안내                           |
| V             | 3인칭 탐험 / 1인칭 블록 만들기 전환 |
| Esc           | 일시 정지 / 메뉴                    |

기본 시점은 캐릭터를 따라가는 3인칭입니다. 멈춘 상태에서 마우스를 돌리면 히나냥의 얼굴을 볼 수 있으며, 움직이면 이동 방향으로 몸을 돌립니다. 나무나 지형이 카메라를 가리면 카메라가 자동으로 가까워집니다. 블록은 캐릭터에게서 7칸 이내이면서 캐릭터와 카메라 양쪽에서 보이는 것만 편집할 수 있습니다. `V`로 기존 1인칭 조작도 사용할 수 있습니다. 기존 월드 생성과 저장 키는 유지되어 이전 블록 변경 사항을 계속 불러옵니다.

플레이어와 겹치는 위치에는 블록을 놓을 수 없습니다. 월드는 57×57칸이며 가장자리, 기반암과 높이 40 이상은 편집할 수 없습니다. 크리에이티브 모드이므로 재료는 무제한입니다. 생존 시스템, 적, 제작과 멀티플레이는 이 버전에 포함하지 않습니다.

블록 변경 사항은 현재 브라우저의 `localStorage`에 자동 저장됩니다. 저장은 브라우저와 사이트 주소별로 독립적이며 브라우저 데이터 삭제 시 사라집니다. 카메라 위치는 저장하지 않습니다. 설정에서 시작 지점 복귀, 그림자와 마우스 감도 조절, 확인 후 세계 초기화가 가능합니다.

## 검증과 배포 빌드

```sh
npm test          # 월드 생성, 충돌, 편집, 저장 복원, 레이캐스트 검증
npm run build    # TypeScript 검사 + dist/ 생성
npm run test:e2e # Chromium에서 렌더링·이동·점프·블록 편집·저장 검증
npm run preview  # 프로덕션 빌드 로컬 확인
```

브라우저 테스트는 `/usr/bin/chromium`이 있으면 사용합니다. 다른 경로는 `CHROMIUM_PATH`로 지정하거나 `npx playwright install chromium`으로 설치할 수 있습니다. 테스트가 자체 Vite 서버를 포트 4173에 띄우고 종료합니다. 이미 실행 중인 개발 서버에는 `TEST_URL`을 지정합니다. 스크린샷은 Git에서 제외된 `.artifacts/`에 생성됩니다. 프로덕션에서는 테스트 진단 객체를 노출하지 않습니다.

`dist/`를 정적 호스팅에 배포하면 됩니다. 모든 게임 에셋과 글꼴은 로컬 번들에 포함되며 게임 중 외부 서비스 호출은 없습니다. HTTPS 또는 localhost에서 실행하세요.

## 온라인에서 실행하기 — GitHub Pages

자동 배포 파일은 `.github/workflows/deploy-pages.yml`입니다. 저장소 관리자가 최초 한 번 다음 설정을 완료해야 합니다.

1. GitHub 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
3. **Actions → Deploy game to GitHub Pages → Run workflow**에서 `main`을 선택하고 실행합니다. 활성화 전에 실패한 실행이 있다면 **Re-run all jobs**로 다시 실행해도 됩니다.
4. `build`와 `deploy`가 모두 초록색 체크로 완료되면 `https://urbanbeyond.github.io/game/`에서 플레이합니다.

이후 `main`에 변경 사항을 push하면 테스트와 빌드를 거쳐 자동으로 재배포됩니다. 방문자는 Git이나 Node.js를 설치할 필요가 없습니다. 비공개 저장소는 계정/조직의 요금제가 Pages를 지원해야 합니다. 지원되지 않더라도 저장소 공개 여부는 별도로 결정해야 합니다.

`vite.config.ts`는 상대 에셋 경로를 사용하므로 `/game/` 아래에서도 게임 코드, 글꼴과 아이콘을 정상적으로 불러옵니다. 로컬 개발 명령은 그대로입니다. 온라인 사이트의 저장 데이터는 로컬 개발 주소와 공유되지 않습니다.

## 구성

- `src/world.ts`: 결정적 지형 생성, 블록 편집/저장 검증, 충돌과 그리드 레이캐스트
- `src/character.ts`: 제공된 픽셀 캐릭터의 입체 모델, 이동 방향과 동작 애니메이션
- `src/camera.ts`: 3인칭 추적·장애물 회피와 1인칭 전환
- `src/scene.ts`: Three.js 렌더링, 픽셀 텍스처, 노출된 블록 면만 생성하는 메시
- `src/main.ts`: 플레이어 물리와 조작, UI, 자동 저장
- `src/style.css`: 한국어 UI와 반응형 레이아웃

클라우드 작업은 기존 `/workspace/game` 체크아웃에서 실행합니다. 별도 Git worktree는 필요하지 않습니다. 서버 프로세스는 환경 복원 후 다시 시작해야 합니다.
